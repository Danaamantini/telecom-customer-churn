# Tableau dashboard

`telecom_churn_dashboard.twb` contains the portfolio workbook. It uses the
single customer-level output generated by the pipeline:

```text
data/processed/clean_customers.csv
```

To open it reproducibly:

1. Run `python run_pipeline.py` from the repository root.
2. Open the workbook in Tableau Desktop or Tableau Public.
3. If prompted, replace the data source with
   `data/processed/clean_customers.csv`.
4. Confirm that `customer_id` and `zip_code` are dimensions and that `churn`
   and `is_fiber` are booleans.

The dashboard should communicate four questions: overall churn, segment
differences, observed recurring revenue associated with churn, and regional
concentration. Rates must exclude customers whose status is `Joined`.

The public Tableau URL and a dashboard preview should be added here after the
workbook is visually checked and published.
