# Tableau workbook

[`telecom_churn_analysis.twb`](telecom_churn_analysis.twb) is a real Tableau
workbook generated with Tableau Desktop. It contains two focused views:

- churn rate by contract;
- churn rate by internet type.

Both use the single customer-level output generated by the pipeline:

```text
data/processed/clean_customers.csv
```

`telecom_churn_dashboard.png` is the static executive dashboard displayed in
the main README. Rebuild it after running the pipeline with:

```bash
python -m src.dashboard_preview
```

To open it reproducibly:

1. Run `python run_pipeline.py` from the repository root.
2. Open `dashboard/telecom_churn_analysis.twb` in Tableau Desktop or Tableau
   Public.
3. If prompted, replace the data source with
   `data/processed/clean_customers.csv`.
4. Confirm that the two sheets render and that the overall churn rate is about
   28.37%. The rate excludes customers whose status is `Joined`.

The workbook intentionally stays small and interview-friendly. It demonstrates
the business definition of churn and two high-signal segments without adding
unsupported financial or geographic claims.

A public Tableau URL can be added here after publishing from an edition that
supports Tableau Public. Tableau Desktop Free can open and edit the workbook,
but its publishing controls may be disabled.
